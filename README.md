# DE-TradingBod-NEXUS-mit-OpenAI-Schnittstelle
NEXUS ist ein Tradingbot für eToro-Aktien und OKX-Spot-Krypto. Er analysiert Kerzen, Markt- und Kontodaten und handelt regelbasiert mit Stop-Loss/Take-Profit. Entscheidungen, Orders und Ergebnisse werden protokolliert. Dynamisches/festes Universum, WebUI, Telegram-Steuerung und Sicherheitsprüfungen; standardmäßig Demo/Paper.
